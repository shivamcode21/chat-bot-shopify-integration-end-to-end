# Little Igloo Extension Install Guide

## Package
- Extension: `littleigloo_extension`
- Locked domain: `littleigloo.in` (including subdomains)

## Install Steps (Chrome)
1. Unzip the package on your computer.
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer mode** (top-right).
4. Click **Load unpacked**.
5. Select the unzipped `littleigloo_extension` folder.

## Verify It Is Working
1. Open `https://littleigloo.in/` (or a subdomain of it).
2. You should see the chat launcher on the bottom-right.
3. Open chat, enter phone number, and send a message.

## Expected Restriction
- The extension is locked and will not run on non-`littleigloo.in` websites.

## If It Does Not Load
- Refresh the website once after installation.
- Ensure you are on `littleigloo.in` or its subdomain.
- Re-open `chrome://extensions` and confirm the extension is enabled.

🎯 How to Integrate on Your Website

Step 1: Get your client name from the Fashion Bot admin panel

Step 2: Add this code before the closing </body> tag:

<!-- Fashion Bot Widget --> <script src="https://YOUR-DOMAIN.com/static/chat-widget.js"></script> <script> FashionBotWidget.init({ clientName: 'YourClientName' // e.g., 'Concept Groove' }); </script>

Step 3: Replace YOUR-DOMAIN.com with your actual Fashion Bot server domain

Step 4: Replace YourClientName with your client name (case-sensitive)

🏆 Features:

  • ✅ Auto-detects server URL (works on localhost, staging, production)
  • ✅ Persistent chat history (48-hour resolution cycle)
  • ✅ Rich text formatting (bold, links, lists)
  • ✅ Responsive design (works on mobile & desktop)
  • ✅ Session management with automatic cleanup
  • ✅ Secure data storage (localStorage)

📋 Integration Code (Production)

Add this to your website to enable the chat widget:

<!-- Fashion Bot Chat Widget -->
<script>
  window.FashionBotWidgetConfig = {
    clientName: 'Your Store Name'  // Must match database
  };
</script>
<script src="https://YOUR-DOMAIN.com/static/chat-widget.js" async defer></script>

Programmatic Control (Optional):

<!-- Open chat with a button -->
<button onclick="FashionBotWidget.open()">Need Help?</button>

<!-- Other methods -->
FashionBotWidget.close();   // Close chat
FashionBotWidget.toggle();  // Toggle open/close
FashionBotWidget.destroy(); // Remove widget

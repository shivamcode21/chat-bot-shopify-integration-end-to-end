Open-source AI commerce infrastructure

EcommAgents — Open-source AI Agent for Shopify

Build an AI shopping and customer-support agent for Shopify with Python, LangGraph, FastAPI, LLMs, and commerce tools.

View the EcommAgents source on GitHub →

Capabilities

  • Product discovery and recommendations
  • Shopify order lookup and status workflows
  • Delivery and logistics orchestration
  • Returns and exchanges
  • WebSocket chat
  • WhatsApp / Gupshup webhook integrations
  • FastMCP commerce tooling

Built with

Shopify · LangGraph · LangChain · FastAPI · FastMCP · PostgreSQL · Redis

Get started

cd ecommagents/fashion_bot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m fashion_bot.main
